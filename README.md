# sec.social: InfoSec Meetups Around the World

A community map of security and tech meetups, conferences, chapters and
student groups. Live at **[sec.social](https://sec.social)**.

## Add or update a meetup

- **Add a meetup:** use the form on [sec.social](https://sec.social), or open a
  [Submit a meetup](https://github.com/admford/SecSocial/issues/new?template=new-meetup.yml) issue.
- **Report one that's ended or wrong:** click "Request removal" in its map popup.

Every submission is reviewed before it appears on the map.
